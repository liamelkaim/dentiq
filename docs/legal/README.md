# Legal and trust working documents (DRAFT, not legal advice)

Written 2026-11-02 from what the code does. A lawyer or privacy professional must review them before launch. **Nothing here claims compliance with Quebec Law 25, PIPEDA or any standard, and nothing says a university has approved Dentiq.**

Rule used in every file: a fact is filled in only when the code or a test proves it (the proof is named). Anything that needs a decision, a contract, a region or a signature is marked **OWNER TO CONFIRM**.

|---|---|

| [retention-schedule.md](retention-schedule.md) | How long each kind of data is kept (code defaults vs owner decisions) |
| [incident-register.md](incident-register.md) | Response steps and the (empty) register |
| [privacy-impact-assessment-template.md](privacy-impact-assessment-template.md) | The assessment to complete before data leaves Quebec |
